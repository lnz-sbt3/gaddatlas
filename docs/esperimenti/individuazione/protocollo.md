# Protocollo dell'individuazione assistita (capp. VI–X) — ricostruzione

Sessioni del 29 luglio – 4 agosto 2026, modello linguistico generalista Claude Opus 5 (Anthropic). Il testo del protocollo non è conservato come documento autonomo. Questa ricostruzione si fonda su due fonti:
- la struttura dei fogli di lavoro restituiti dal modello (colonne elencate sotto);
- le note che accompagnano le righe.

## Campi richiesti per ogni menzione di uno spazio

| Colonna del foglio | Contenuto |
|---|---|
| Reference_ID | identificatore provvisorio della menzione |
| Surface_Toponym | forma in superficie |
| Excerpt | estratto (non pubblicato) |
| Modalita | esplicita, perifrastica, anaforica, deittica, allusiva |
| Source_Reference, Page_Count | pagina dell'edizione Adelphi |
| Luogo_proposto | identificatore del luogo proposto |
| Stato_luogo | ESISTENTE (già nel dataset), NUOVO, SCARTATO |
| Anchor_proposto | entità del gazetteer proposta come ancora |
| Reality_Status_ipotesi | ipotesi di statuto di realtà |
| Agenti_coinvolti, Confidence_agente | personaggi associati e grado di confidenza |
| Route_sospetta | eventuale percorso segnalato |
| Nota | motivazione, soprattutto per gli scarti |

## Regole desumibili dalle note

1. **Inclusione larga.** Ogni spazio fisico andava proposto; la selezione era riservata all'autore.
2. **Scarti conservati.** Le menzioni escluse dal modello restano nel foglio con stato SCARTATO e una motivazione (per esempio uso figurato, spazio escatologico, oggetto o arredo).
3. **Ancore ambigue.** Quando l'ancoraggio era ambiguo, le alternative venivano duplicate.
4. **Percorsi.** I percorsi andavano solo segnalati; nessuna decisione sul tipo.
5. **Esempi.** Come esempi erano fornite le tabelle del dataset annotato dall'autore per i capp. I–V.

## Taratura

Secondo le note di lavoro del 29/07/2026, la procedura è stata provata sulle pp. 140–151 e ha ritrovato gli undici luoghi del ciclo precedente. Il foglio di questa prova non è conservato.
